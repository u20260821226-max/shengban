# 声伴代码说明

## 当前版本

个人项目，使用 AI 辅助开发。项目发起者负责需求取舍、曲目准备、Audiveris 识谱、MuseScore 人工校对及导出、体验测试和验收；AI 辅助实现网页、播放器和乐谱显示代码。具体个人工作以真实记录为准。

预置《爱永在》《小幸运》《有一种悲伤》可独立播放。云端另接入有限范围的图片识谱：选择两行或三行五线谱，一次最多六页，自动生成连续试听；不要求用户人工校谱。账户骨架未接入，公网任务采用匿名浏览器身份隔离。Audiveris 是识谱后端依赖，MuseScore 仅用于人工准备示范曲目。

## 模块与数据流

1. `index.html` 提供页面结构；`styles.css`、`practice.css` 提供样式。
2. `practice-app.js` 管理曲目选择、页面状态、控件与两个播放器模式。
3. `music-player.js` 读取音符事件，使用 Web Audio 和本地钢琴采样播放；负责变速、移调、循环、倒数。
4. `score-view.js` 调用本地 OSMD，显示 MusicXML 并同步移调。
5. `sw.js` 按 `asset-list.json` 缓存资源，使完成首次缓存的浏览器可离线运行。

素材处理流程：原谱 → Audiveris 识别 → MuseScore 人工校对 → MusicXML / MIDI / MP3 → 预处理音符 JSON → 网页曲库。
MusicXML 用于谱面，MIDI 衍生 JSON 用于可调速移调播放，MP3 用于原调原速备用播放。

## 文件分类

- `assets/scores/`：三首曲目的 MusicXML、MIDI、音符 JSON。
- `assets/audio/`：纯伴奏、旋律提示两种备用 MP3。
- `assets/piano/`：钢琴音色与授权文件。
- `vendor/`：本地乐谱渲染库及授权文件。
- `backend/omr/`：图片预处理、无损多页书本输入、Audiveris 适配、MusicXML 转音符与节拍检查。
- `backend/public_api.py`、`public_limits.py`：公网任务、归属校验、配额与有界处理。旧 `backend/app/` 账户骨架未接入。
- `recognition-view.js`、`labs/recognition.*`：站内上传、页序、进度、恢复与试听；用独立 DOM 作用域隔离控件和样式。
- `deploy/`：systemd 服务及 Caddy 网关；代码包不包含真实登录密钥。
- `archive/prototype/`：旧原型代码，不被当前网页引用。
- `docs/`：工程及提交说明。
- `scripts/`：资源校验与打包工具。
- `work/`：开发依赖、测试脚本、截图、下载和临时结果，不整体提交或发布。
- 根目录中文乐谱、音频文件：用户原始工作材料，保留原位置；网页使用 `assets/` 内副本。

## 维护规则

新增曲目时同步准备两种播放模式、MusicXML、音符 JSON 和备用 MP3，更新页面曲库及 `asset-list.json`。资源变更时更新 `sw.js` 缓存版本，并验证离线缓存。

保持页面控制、音频调度、谱面渲染分离，不把识谱服务或账户逻辑塞入页面文件。当前体量无需为了分层额外引入大型框架。

资源授权见 `assets/ATTRIBUTION.md`。网页发布包包含歌曲素材，打包完成不代表取得公开传播授权，也不代表已部署公网。
