# 自动识谱试用版范围（2026-10-25 更新）

## 产品目标

用户上传符合范围的谱图后，系统自动识别并提供钢琴试听。用户不需要安装识谱软件、预先准备 MusicXML/MIDI 或进入人工校谱流程。允许少量识别错误，不能把明显错乱的结果当作成功。

单页云端上传识谱已跑通《花非花》；新增两行钢琴及最多六页的连续识谱，已有本机与公网测试记录，详见公网部署说明。尚未验证能普遍达到“少量错误”。现有三首人工校正的预置曲目保持可用，不作为自动识谱准确性的证据。

## 首轮候选范围

- 同一首歌的1至6页印刷五线谱：1至6张JPG/PNG图片，或一份最多6页PDF，每个文件最多10 MB。PDF按文档页序自动转页，不能与图片混传。谱线完整、正向、无明显遮挡与裁切。
- 可选三行声乐谱（人声旋律＋钢琴双手），或两行钢琴谱（右手＋左手）；一次上传不能混用谱型，每页最多 16 小节，全曲最多 96 小节。
- 固定 2/4、3/4 或 4/4 拍，最多三个升降号。
- 先排除手写谱、复杂复调、连音组、反复跳房子与中途换拍。
- 三行谱必须能识别人声与钢琴声部的边界；“纯伴奏”仅播放钢琴双行，“旋律提示”用钢琴音色播放全部三行。无法可靠区分声部时终止处理，不把全部声部冒充纯伴奏。两行谱完整播放双手，不提供旋律分离。

以上是降低风险的候选范围，不是已经验证的算法能力。图片解码检查不能可靠判定全部音乐难度条件；未实现的检测不得在页面宣称自动识别。

## 两阶段检查

1. 上传前后检查：文件格式、可解码性、大小与像素预算、页面方向与裁切提示。输出“可以尝试识别”或具体拒绝原因；单凭图片像素不能判断识谱准确率，也不能用“分辨率低”代替所有失败原因。
2. 识别后检查：检查输出是否可解析、是否有音符、谱表与声部是否符合范围、拍号与小节时值是否存在可检测的明显异常。异常则终止并提示暂不能处理，不输出乱码伴奏。

没有检测到结构异常不代表音高正确。不能自动验证的错音可能通过检查；不输出虚构准确率或未经校准的置信度。若试验仍出现明显错误，需缩小范围或暂停对外开放识谱。

## 用户路径与状态

选择谱型 → 选择图片并调整页序 → 范围说明与文件检查 → 正在识别 → 正在检查结果 → 生成钢琴试听 / 未能处理（具体原因与重试建议）。

不要求用户手工修正乐谱。结果页简短说明“自动识别试听，可能有错音或节奏偏差”，提供重新上传及返回示例曲目入口。

## 技术约束与下一步

- 当前 FastAPI 账户骨架的 `needs_review` 和“等待用户校对”状态不符合新路径；本机新入口独立实现，不使用此旧流程。公网接入时不得将该旧骨架直接作为已完成的识谱功能。
- Audiveris 通常输出 MusicXML；识谱、结构检查、音符转换、网页播放各自独立，不强制引擎同时生成 MIDI。
- 阿里云服务器现同时托管网站与识谱后端；曲库、上传和试听在站内切换。原 Cloudflare 静态版本仍需更新；它通过入口跳到统一的云端应用，不跨域调用 API。
- 本机与公网的有限范围链路已实际运行。后续重点是用更多真实谱验证成功、失败及等待体验，不重复人工校正三首示例来冒充自动识谱测试。
- 依据真实试用结果调整支持范围，不承诺五天内必然达到准确性目标。2026-10-26开始比赛候选版验收和功能范围冻结，见 docs/比赛版本验收与冻结.md。

## 已有经验依据

用户回顾：《爱永在》校正最少，《小幸运》其次，《有一种悲伤》最多；《唯一》《多远都要在一起》《天空没有极限》识别严重错乱，软件曾提示图片分辨率低。原始像素、处理耗时和逐音准确率未重新测量，不编造定量指标。
