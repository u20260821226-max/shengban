# 小节上限调整与验证（2026-11-03）

本机新版将每页上限由16提高到64小节，全曲由96提高到384小节，仍最多6页。限制集中在 backend/omr/pages.py，识谱输出检查和MusicXML转换共同使用；上传页提示同步修改。

小节上限是处理量保护，不是音乐难度或准确率标准。小节增多通常增加音符事件、MusicXML体积、结果校验和谱面排版的开销；识谱阶段还受图像尺寸、谱表数量和排版密度影响，实际耗时与小节数不成固定比例。复杂短谱也可能失败，规则长谱也可能成功。

文件大小、像素上限、六页上限、固定拍号、调号、节拍检查、两次完整识别尝试和有界的前段恢复仍保留，识谱超时按原150秒×页数控制。放宽小节数不等于放宽错误检查、不等于增加全站每日页额度，也不能保证服务器能在时限内识别密集64小节页面。

验证：后端81项检查通过；新增64小节单页生成、384小节六页连续计时、65小节单页拒绝、单页计数及总页数边界检查。最大长度样本返回1152个音符、384小节、768秒，最后小节从766秒开始。这里是结构化测试乐谱的转换与调度时间验证，不是对真实384小节谱图的Audiveris识别验证。

本轮仅更新本机代码与交付包，未部署公网、未同步GitHub。旧日期的验收材料中16/96小节属于当时的历史配置，不追溯改写。
