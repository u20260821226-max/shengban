# 追加谱页与识别诊断修复（2026-11-03）

上传图片后显示“继续添加谱页”，原有选择入口改为“重新选择全部”。每次新增的一批按文件名排序，再接到原队列尾部；页序可手动调整。按名称、类型、大小、修改时间去重，不承诺内容级去重。取消选择、格式错误、超六页均保留此前选择；达到六页禁用追加，移除后恢复。PDF单独选择，不能追加图片。处理期间所有文件操作禁用。改变文件后隐藏旧结果和旧任务恢复按钮，避免误认归属。

节拍检查在整条谱表缺失时明确指出旋律、上行或下行，并说明异常来自识别结果，不代表原谱拍数错误。两次识别均不确定时保留首次和重试原因，避免后一轮漏识别掩盖前一轮问题。成功重试仍按原流程输出；未通过检查不补音、不修改时值、不生成试听。原有失败任务不追溯修改。

真实本机失败样本诊断：首次第4小节上下行均有时值，第5小节上行总计4.5拍（原谱末尾八分音符被读为四分音符）；改变图像尺度后第4小节整个下行全音符漏读。额外4倍放大实验仍在第5小节超拍，因此此修改没有解决该歌曲的识别准确性问题，不应宣称这首已经识别成功。
