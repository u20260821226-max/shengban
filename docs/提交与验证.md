# 代码提交与验证

## 生成交付文件

双击 `scripts/整理代码.command`，成功后自动打开 `dist/`：

- `声伴-网页发布包.zip`：网站运行文件、音乐素材与第三方授权。可交给静态网站托管平台；不包含后端、临时文件、原始编辑文件。
- `声伴-代码提交包.zip`：当前网页源码、运行素材、后端骨架、文档和打包工具，供比赛审阅及后续开发。解压后可双击“启动声伴.command”。
- `资源校验清单.json`：运行文件 SHA-256，可用于确认交付文件内容。

命令方式：`python3 scripts/package_demo.py`。脚本校验资源存在性、路径范围与基础曲谱数据，并按明确清单打包。该校验不能代替实际试听。

## 演示检查

1. 双击根目录“启动声伴.command”，保持打开的终端窗口。
2. 逐首进入三首曲目，分别试听纯伴奏和旋律提示。
3. 检查暂停、从头、跳转、移调、调速、A/B 循环及倒数。
4. 确认乐谱显示，备用 MP3 可播放；MP3 保持原调原速。
5. 完成首次缓存后断网重载；另检查手机宽度。

已有开发验证脚本保留在 `work/player-check.mjs`、`work/browser-check.cjs`、`work/third-check.cjs`，依赖本机 `work/build/node_modules`；不是代码包的免安装测试工具。有关截图可选作项目过程证据，需按实际日期说明，不能当作公网部署证明。

## 提交边界

当前尚无远程代码仓库；压缩包是本地交付物，不等于已经推送 GitHub。`.gitignore` 已排除临时文件、真实环境配置、数据库、上传内容和根目录原始工作文件。后续建仓库前仍应核对待提交文件。

比赛代码说明可如实写“个人项目，AI 辅助开发”，结合个人识谱校对、需求决策及测试过程记录。未接入后端、任意图片自动识谱和公网部署不能列为已完成。
