# 单行钢琴谱接入与验证（2026-11-03）

## 本次新增

新增“单行钢琴谱”谱型（single）：每组一个五线谱表，可以在同一页排多组，使用钢琴音色完整播放，不分离主旋律。支持最多四个降号或三个升号，包含三个降号的降 E 大调 / C 小调、四个降号的降 A 大调 / F 小调等调号；不自动改调。

JPG/PNG、PDF 以及同歌最多六页沿用既有输入流程。固定 2/4、3/4、4/4 拍，每页小节上限后续提高到64，全曲384小节（本机新版）；复杂反复、连音组等既有限制继续有效。两行及三行谱仍限最多三个升降号。

谱型定义集中在 backend/omr/layouts.py，供上传检查、识谱结构检查、MusicXML 转换使用。单行音符标记为 accompaniment，供现有钢琴播放器完整播放。显式 pitch/alter 作为音高依据，不重复应用调号，保留还原音。新增独立的浏览器任务恢复键及 #upload-single 入口，旧两行/三行恢复键兼容。

## 验证结果与边界

1. 后端63项测试通过，其中新增8项单行测试，覆盖三/四降号音高、还原音、跨页延音、谱型隔离、超拍拒绝、调号边界及公网API接收/工作线程参数传递。API路由测试使用注入识谱器，不冒充真实公网识谱。
2. 使用本机 Audiveris 对两份自行制作的简单谱图实际识别：三降号、四降号各4小节、16个四分音符，均一次识别完成。返回MIDI音高逐项与测试谱一致；分别为 [70,63,68,62] × 4 和 [70,63,68,61] × 4。
3. 四降号谱图由 MuseScore 排版导出；三降号谱图由 OSMD 排版后置于白色页面。第一次三降号紧裁截图因短边不足400像素被既有输入检查拒绝，随后改用完整页面。MuseScore第二次导图崩溃，故三降号使用OSMD替代排版，此为测试素材制作问题。
4. 390及1280像素浏览器检查：三种谱型入口、单行选择、上传、完整钢琴模式、实际播放器运行、乐谱显示、刷新恢复和三种任务键隔离通过。页面验证复用实际识别结果，通过本地模拟API响应检查交互，不重复消耗公网额度。截图已目视检查。
5. 另在390像素本机页面完成真实端到端流程：上传四降号谱图 → 本机FastAPI → Audiveris → 结果和谱面 → 播放。成功生成1页、4小节的结果，播放器进入播放状态。此项未模拟识谱API，也未使用公网额度。
6. 样本和原始识别结果保存在 work/single-staff-20261103/，不默认发布到网站或源码包。

这是本机代码与简单样本的验证，不证明任意真实单行曲目都准确。未用用户真实新谱验收；未部署本次改动到公网，未同步GitHub。
