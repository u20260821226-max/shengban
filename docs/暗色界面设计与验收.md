# 暗色界面设计与验收

2026-10-26，用户要求将现有声伴页面美化为高级暗色调。此轮是已有产品的界面统一，不重写识谱与播放架构。

## 前端认知与取舍

- 项目阶段：核心功能已可用的比赛DEMO；页面类型：声乐练习工具。
- 用户与任务：声乐学习者，首先选择预置曲或上传新谱，再试听、切换模式和调整练习参数。
- 核心对象：曲目、谱面、播放声部、识谱任务；成功标准为操作明确、文字和谱面可读、播放与上传路径不变。
- 风格：安静的音乐工作室。延续现有声伴品牌和导航结构，以炭黑、墨绿、暖金及浅纸色建立统一层级。
- 组件基础：沿用原生HTML/CSS/JS与现有播放器、OSMD；已有组件结构决定视觉实施范围，不另建营销页，不加入框架和大图片依赖。
- 设计参考：录音室控台的清楚分组、乐谱册的文字层级；不用装饰性数据、假的账户或无功能按钮。
- 信息优先级：曲目与播放、上传入口、当前状态，其次说明与限制。内部协议及源码细节留在文档。
- 手机主操作：选曲/导入与播放，按钮至少44像素，谱面支持展开与滚动，避免横向溢出。
- 风险：暗色文字对比不足、把谱面也染黑而看不清、阴影边界不明、Shadow DOM上传页面颜色不一致、离线缓存仍停在旧主题。
- 验证：1440/390/320宽度，曲库搜索和空结果、三首播放、模式、移调、变速、全谱展开、弹窗、PDF选择与错误、移动端、焦点及减少动画设置。浏览器模拟不得冒充新的真实识谱验收。

## 改动原则

视觉令牌单独放在theme.css，应用与曲库样式在styles.css，练习样式在practice.css，上传工具在labs/recognition.css。沿用CSS与SVG实现，保留真正的MusicXML谱面。

保留所有既有功能和可分享网址。去除静态原型里的虚构姓名、账户菜单及可能引起误解的保存状态。仍保持“预置曲库”和“自动识谱试用”能力边界。

实际验证、上线及更新包结果完成后记录在文末。此文件建立时不预先声明验收通过。
