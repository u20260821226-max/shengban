# 部分识别结果与验证（2026-11-03）

## 行为

完整生成失败后，自动尝试保留从第1页开始的连续前段。比如第6页检测失败，可重新识别并检查前5页；第3页失败时，仅尝试前2页，不将第4页跨过第3页拼入结果。第一页即失败时，没有可保留的前段。

前段仍需通过既有谱型、拍号、调号、时值、声部、小节数和跨页衔接检查。截断位置存在未闭合延音线时，继续退到更早的完整页边界；没有安全边界就拒绝输出。不删除延音标记、不强行缩短音符，也不补造音符来制造成功。

结果明确区分 completed（完整）、partial（部分）、rejected（拒绝）、failed（故障/超时）。部分结果包含 coverage：原上传总页数、保留页数、未包含页码和原因。界面显示“仅前X/共Y页”，提供部分试听和MusicXML乐谱下载；下载文件名和文件内标题均带部分结果标记。MusicXML重新排版后的纸面页数可能变化，X指原上传页序，不是导出后的固定纸张数。

本轮不是PDF导出、付费下载或自动补页合并功能。用户可以单独识别未包含页，或替换问题页后重新提交全曲。不同任务不会自动拼接。

## 耗时、额度及权限

- 保留原有完整识别流程，结构疑点最多重试一次。
- 完整流程失败后，最多额外启动两次前段识别；这些恢复运行不再各自重试，并共享“150秒 ×（原上传页数−1）”的识谱时间预算。可能在找到可用前段之前触及次数/时间限制，不能承诺所有失败均能恢复。
- 失败原因中页码只用于选择候选输入，必须重新识别并检查候选，不能当作前面页面正确的证明。
- 恢复属于同一任务，不重复扣任务次数。原上传全部页数计入24小时额度，恢复/保留页数少于上传页数时不退还额度。
- partial是终态：释放任务槽、记录结束时间、重启后保留结果，约24小时后清理。刷新按任务编号恢复部分结果；重新提交相同原图可启动新的识别，不强制复用部分结果。
- 下载仍使用带浏览器身份请求头的原有乐谱接口。跨浏览器返回404，缺少身份返回401；没有把私人谱面变成公开直链。
