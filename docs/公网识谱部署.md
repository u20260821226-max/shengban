## 结构与边界

- `backend/public_api.py`：独立 FastAPI 服务，127.0.0.1:8000，单进程单识谱 worker；与本机标准库服务、旧 app 账户骨架分开。
- `public_limits.py`：浏览器随机 256-bit token 的摘要作为任务 owner；状态和 XML 都校验归属。token 仅经请求头发送，不写入 URL、日志或源码。
- 同浏览器同图复用；不同浏览器不能访问或复用对方的结果。不是注册登录系统，清除浏览器存储后无法恢复旧任务。
- 一次上传 1 至 6 页，每页 10 MB，JPEG/PNG；两行钢琴或三行声乐谱。最多两个识别尝试，每次上限 150 秒乘页数；顺序处理并释放已处理页数据。一个任务正在运行时，其他新图立即提示忙，不建无限队列。
- 10月26日新增单份最多六页、10 MB PDF，独立限时进程自动转页后进入相同流程，配额按真实页数计算。转换依赖为pypdfium2 4.30.0，验证见《PDF接入与验证》。
- 每浏览器滚动 24 小时最多 5 次任务，全站最多 30 页；持久任务记录在重启后保留配额。额外的 IP 上传频率限制为每小时 20 次。匿名 token 可重新生成，因此全站配额才是最终资源上限。
- 任务约 24 小时后清理，服务运行时每分钟检查一次；重启也清理过期任务。正在处理任务不会半途删除。重启中断的任务标记失败，不虚构成功。
- Java 堆上限 2 GiB，服务 cgroup 内存上限 3 GiB；低权限用户运行，不对外暴露工作目录、源文件、原图或日志。
- 音频仍由浏览器钢琴采样与返回音符数据播放，不额外生成可下载 MP3。少量错音、漏连线仍可能存在；不宣称达到固定识别准确率。

## HTTPS 与网站

地址为 `https://47-83-177-119.sslip.io`，这是解析到服务器 IP 的免费第三方域名，HTTPS 证书已签发；不是购买的自有域名，依赖 sslip.io 的解析可用性。

`deploy/Caddyfile` 只把 `/api/*` 转发到后端，其他路径从白名单构建的网站目录读取。80 用于 HTTPS 跳转与证书验证，443 提供网站；8000 不对公网开放。

`recognition-config.json` 已指向验证后的 HTTPS 识谱页；服务器版本由部署脚本设为同源 `/labs/recognition.html`。Cloudflare 仍需用户重新上传本次网页发布包，原部署不会自行更新。只更新 GitHub 不会自动部署。

Service worker 不缓存 `/api/*` 或识谱配置，避免过期状态和私有谱面进入离线缓存。

## 安装与运行记录

1. 官方 Audiveris 5.11.0 Ubuntu 22.04 DEB，自带 Java。下载 SHA-256：`ae714594f40e54b1a4951fc3f914f08ae38fe5d07b7f2283b1a904fdb6e0a318`。服务器无桌面菜单目录时先创建 `/usr/share/desktop-directories`，再完成 dpkg 配置。
2. 安装 Python 3.10 venv、Noto CJK 字体；依赖见 `backend/public_requirements.txt`。Audiveris cfg 中将 `-Xms512m/-Xmx8G` 改为 `-Xms128m/-Xmx2G`。
3. Caddy 2.11.7 官方 linux amd64，包 SHA-256：`727b91701a392de6ebc5027509f548bf39979e5216340d0faed8fa5e69c84f8b`。
4. 本地运行 `python3 scripts/package_server.py`，只传 `dist/shengban-server.tar.gz` 到服务器 `/opt/shengban/downloads/`，解压到 `/opt/shengban/`。包中不含部署密钥、用户原图或识谱任务。
5. 服务器创建 `/opt/shengban/venv`，安装 public_requirements，然后以 root 执行 `bash /opt/shengban/deploy/activate.sh`。脚本创建服务用户、私有存储和 systemd 服务。
6. `systemctl status shengban-api shengban-web` 查看状态；`journalctl -u shengban-api` 排查后台错误。网站端口未放行时暂停 web 服务避免重复失败的证书申请；放行后 `systemctl start shengban-web`。

默认不是容器方案，无需购买其他服务。服务器按量计费、试用额度和流量仍以阿里云账户账单为准。比赛后释放资源需由用户明确操作，停止实例不一定停止所有资源收费。

## 验证

开发环境先安装 public_requirements 与 httpx，再运行 `python -m unittest discover -s backend/tests -v`。40 项测试通过，覆盖原有节拍/超时/恢复及新增跨浏览器隔离、XML 权限、配额、并发拒绝、上传边界、重启恢复。

云端真实识谱、手机播放、HTTPS 公网访问需各自记录结果，不能用本地测试或 SSH 隧道测试代替公网验收。

本次已用真实《花非花》从 API 上传到云服务器，经两次自动识别约 153 秒返回 10 小节。通过私有 SSH 测试隧道连接云端 API，浏览器验证了带权限 XML 的谱面、两种播放模式、刷新恢复和 390 像素手机排版，无页面脚本错误。这只证明云端处理及浏览器对接成功，尚不代表公网 HTTPS 已可访问。内存观察值约 1 GiB，不能据此保证所有输入的峰值内存。

端口放行后补充公网验收：真实 HTTPS 浏览器已通过曲库“导入新乐谱”跳转、上传 POST 202、同浏览器同图复用、受保护 XML 谱面、纯伴奏/旋律提示播放、390 像素手机排版及其他浏览器读取任务返回 404。没有忽略证书错误；截图保存在开发工作目录 `work/public-https-desktop.png` 与 `work/public-https-mobile.png`。云端 Java 识别耗时来自上一段真实运行，本轮上传复用了同一结果，没有谎报第二次识别运行。
