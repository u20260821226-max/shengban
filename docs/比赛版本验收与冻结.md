# 比赛版本验收与冻结

版本：2026-10-26 RC2（新增PDF的比赛候选版）。RC1快照保留，按用户后续要求新增PDF后另存RC2。功能范围冻结是暂停增加大功能、允许修复影响演示的问题；用户明确调整范围时，重新开发、验收和保存候选版。冻结不是停止网站，也不是代码从此不能修改。

## 冻结范围

- 三首预置曲：《爱永在》《小幸运》《有一种悲伤》。
- 纯伴奏、旋律提示、移调、变速、进度、A—B循环、备用录音和全谱查看。
- 有限范围的自动识谱：同歌1至6页JPG/PNG，或一份最多6页PDF；选择两行钢琴或三行声乐，自动处理、结构检查、一次重试、结果恢复及试听。
- 公网统一入口：https://47-83-177-119.sslip.io/ 。
- 不在本轮新增登录、个人曲库、在线校谱编辑器、自动图片移调或更换识谱引擎。

## 本轮验收方式

2026-10-26，对实际公网HTTPS入口检查，不通过本机服务或SSH隧道代替。

1. 运行后端46项既有测试，全部通过，涵盖节拍、跨页、权限、配额、输入、恢复等。
2. 逐个下载并计算61个公网运行文件的SHA-256，与本地对应文件一致。配置文件因部署时使用同源入口，不在这61个文件的对比范围内；这项检查也不等于已比对服务器后端源码或GitHub提交。
3. 浏览器检查三首曲目的两种模式、谱面移调、调速、跳转、循环设置、备用MP3及390像素手机排版，全部通过。
4. 资源完成缓存后断网重载，验证预置曲目可以播放。自动识谱仍需联网。
5. 检查三首曲目的两模式音符调度数量：207/244、289/444、242/356，均与对应数据相符。这是程序播放检查，不是原谱逐音准确率统计。
6. 用新的浏览器身份重新上传简单六页钢琴结构谱，以及真实单页《花非花》。不借用昨天的任务结果，检查实际云端处理、刷新恢复、谱面权限、模式和手机操作。实际耗时与结果见下方补充。

开发原始证据：`work/acceptance-2026-10-26/result.json`、同目录截图与 `work/release-acceptance.cjs`。原始证据保留本机，不默认放进网站或源码提交包。

本轮实际结果：

- 六页简单两行钢琴谱：新任务完成，49秒、6小节、48音符、1次识别；刷新未重复提交，谱面、完整钢琴播放、站内返回和手机排版通过。
- 单页真实三行《花非花》：新任务完成，93秒、10小节、239音符、2次识别；两种模式、受保护谱面、刷新恢复和手机排版通过。
- 两个任务中，换成其他浏览器身份读取均返回404；缺少身份返回401，不存在任务返回404，跨站提交返回403，不支持的文件类型返回415，后台源文件路径返回404。
- 新识谱任务提交时服务忙会返回429并提示稍后重试，本轮也实际观察到该限制，没有绕过并发控制。
- 测试脚本起初错误地假设两种谱型使用相同形式的存储键，导致误报等待超时；已修正脚本并完成三行重新验收。这是测试工具问题，原始失败记录保留，不计为产品故障或识谱失败。

这些秒数仅为本轮样本耗时，不能承诺其他曲目相同速度。汇总结果为 `work/acceptance-2026-10-26/验收结果.json`，原始第一轮记录为 `first-run.json`，三行完成记录为 `vocal-retest.json`。

## 已知限制与提交口径

新增PDF后55项本地测试通过，转换与公网验证见《PDF接入与验证》。早先46项及图片云端数据保留为RC1阶段记录，不冒充新增PDF的验收数据。

RC2新增公网验收：四页钢琴PDF21秒，一页三行声乐PDF11秒，均生成结果并通过刷新、谱面权限、播放及手机视口检查；七页和损坏PDF得到具体拒绝说明。它们是简单结构样本，非真实复杂六页谱，且后台耗时不含上传/转页。

- 简单六页测试仅为6小节、48音符；末页复用第五页。通过说明批量输入与连续播放通路可用，不代表复杂六页歌曲准确。
- 《爱乐之城》前六页59小节合并成功，但真实识谱的超拍与错误连音导致自动生成失败。本轮不反复重跑，不把旧失败改写成成功。
- 本轮手机检查使用浏览器390像素视口，不等同于另一部实体手机、独立运营商网络的验收；手机扬声器实际声音需本人确认。
- 自动检查验证了播放状态、音频节点调度及备用录音推进；错音、连线、音量与练声体验仍需人工试听。
- 识谱有等待、失败、资源配额和试用期限限制，不能承诺任意谱、固定生成时间或固定准确率。
- 线上运行资源已核对；PDF转换、上传解析和API三个关键后台文件另已与本地核对哈希。没有把这项检查扩大为全部后台源码逐文件一致；GitHub最终提交仍未独立核验。
